# Incident log

One file per P1 or P2 incident (deploy/SUPPORT.md), named `YYYY-MM-DD-short-name.md`, written by the developer
on call within a day of the fix. Never paste customer phone numbers, addresses, tokens or keys here; use order
numbers and request ids (`req_...`).

```
# <date>: <what customers saw>

- Started / noticed / fixed: <IST times>, noticed by <alert or person>
- Cause: <one or two sentences>
- What changed: <commit, setting or runbook update>
- Customers affected and what they were told: <count, message>
```
